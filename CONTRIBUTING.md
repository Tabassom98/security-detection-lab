# Contributing

Use Python 3.10+. Run `python -m unittest discover -s tests -v` before proposing a change. Keep the default demo deterministic and update expected alerts only when behavior intentionally changes. Explain the hypothesis, input assumptions, false positives, evasion paths, and test evidence for each new rule. Use synthetic or explicitly approved sanitized data; never include credentials or private logs. AI-assisted contributions should be disclosed. Avoid unsupported efficacy claims.
