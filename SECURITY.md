# Security and data handling

This is an offline educational lab, not a security service. It reads only the selected local file and writes alerts to stdout. Alerts can include usernames and IP addresses, so use synthetic data for public examples and protect real outputs according to your organization's rules. No network requests or automated remediation are implemented.

Do not open a public issue containing credentials, private logs, or exploit details involving another system. Use GitHub's private vulnerability reporting if enabled on the published repository. If it is unavailable, use a public issue only to request a private contact channel without disclosing sensitive details. Private reporting is not claimed to be enabled before setup is complete.
